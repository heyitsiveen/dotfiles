# MCP Servers

MCP (Model Context Protocol) servers extend Claude Code with external tools and data sources. Configuration lives in `.claude.json`.

| Server                  | Description                                          | Docs                                                                                                |
| ----------------------- | ---------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| **Context7**            | Up-to-date library documentation and code examples   | [Docs](https://context7.com/docs/overview)                                                          |
| **Exa**                 | Web search, company research, and code context       | [Docs](https://exa.ai/docs/reference/exa-mcp)                                                       |
| **Grep**                | Search code across a million GitHub repositories     | [Docs](https://vercel.com/blog/grep-a-million-github-repositories-via-mcp)                          |
| **Better Auth**         | Better Auth framework documentation and APIs         | [Docs](https://www.better-auth.com/docs)                                                            |
| **Shopify Dev**         | Shopify API tools and schema introspection           | [Docs](https://shopify.dev)                                                                         |
| **Figma**               | Official Figma design-to-code and FigJam integration | [Docs](https://help.figma.com/hc/en-us/articles/32132100833559-Guide-to-the-Figma-MCP-server)       |
| **Shadcn UI**           | Browse, search, and install shadcn/ui components     | [Docs](https://ui.shadcn.com/docs/registry/mcp)                                                     |
